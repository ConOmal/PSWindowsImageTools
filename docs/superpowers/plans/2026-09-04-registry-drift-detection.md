# Registry Drift Detection — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add registry drift detection to the existing snapshot/compare pipeline of PSWindowsImageTools — a new `Registry` category on `ImageSnapshot` and a per-hive `RegistryDriftResult` on `ImageComparisonResult` — without adding any cmdlets.

**Architecture:** Mirror the existing convention: `Models/*.cs` for the new types, `Services/RegistryDriftService.cs` for the work, and pure `internal static` methods for every piece of logic a unit test can drive without hive files or DISM (key selection, value normalization, capture projection, diffing). The only thin, non-unit-tested surface is the hive read itself (`IRegistryHiveReader.OpenHive`/`GetKey` + the `Registry.dll` `RegistryKey.Values`/`SubKeys` enumeration), which reuses the module's existing in-memory hive-reading pattern — this `Registry` package surface already has real-hive coverage via `RegistryHiveReaderTests.cs` and manual verification.

**Tech Stack:** C# / .NET (netstandard2.0, LangVersion 8.0, nullable enabled per existing `.csproj`), Newtonsoft.Json (existing dependency), xUnit (`tests/PSWindowsImageTools.Tests/`).

**Spec:** `docs/superpowers/specs/2026-09-04-registry-drift-detection-design.md`

### Task 2: RegistryDriftService — pure logic + thin hive capture

**Files:**
- Create: `src/Services/RegistryDriftService.cs`

**Interfaces:**
- `RegistryDriftService(ModuleCallbacks? callbacks = null)` — public ctor, `ModuleCallbacks.Silent` default (mirror `RegistryHiveReader`).
- `public const string SoftwareHiveName` / `public const string SystemHiveName`.
- `public static List<RegistryDriftKeyDefinition> GetDefaultDriftKeyDefinitions()` — the 16-entry documented set from the spec.
- `public List<RegistrySnapshotValue> CaptureDriftValues(IRegistryHiveReader reader, string mountPath, IReadOnlyList<RegistryDriftKeyDefinition>? definitions = null)` — thin; the only method that touches `IRegistryHiveReader`.
- `internal static string ResolveHivePath(string mountPath, string hive)`.
- `internal static List<RegistrySnapshotValue> CaptureValues(string hive, RegistryDriftKeyDefinition definition, IEnumerable<(string ValueName, string ValueType, string ValueData)> values)`.
- `internal static List<RegistrySnapshotValue> CaptureSubKeyNames(string hive, RegistryDriftKeyDefinition definition, IEnumerable<string> subKeyNames)`.
- `internal static void AppendCapture(string hive, RegistryDriftKeyDefinition definition, IEnumerable<(string ValueName, string ValueType, string ValueData)> values, IEnumerable<string> subKeyNames, List<RegistrySnapshotValue> output)`.
- `internal static string NormalizeValueData(string? data)`.
- `internal static RegistryDriftResult CompareRegistry(string referenceName, string differenceName, List<RegistrySnapshotValue> reference, List<RegistrySnapshotValue> difference)`.

- [x] **Step 1: Write `RegistryDriftService.cs`** with all members above:
  - `CaptureDriftValues`: group definitions by hive (ordinal-ignore-case); resolve hive path; if `!File.Exists(hivePath)` → `_callbacks.Verbose` + skip (never throw); `var hive = reader.OpenHive(hivePath)` once per hive group; per definition call `reader.GetKey(hive, def.KeyPath)` (skip null); project `key.Values` (skip null values; `ValueName ?? ""` with `(Default)` when empty; `ValueType ?? "REG_SZ"`; `NormalizeValueData(v.ValueData)`) and `key.SubKeys.Select(s => s.KeyName)`; funnel into `AppendCapture`; drive all writes to `output` through `AppendCapture`. Per-definition try/catch → `_callbacks.Warning` + continue.
  - `CaptureValues`/`CaptureSubKeyNames`: pure projections, each item sorted by `FullPath`.
  - `AppendCapture`: routes by `definition.Mode` to `CaptureValues` or `CaptureSubKeyNames` and `output.AddRange`s the result.
  - `NormalizeValueData`: null → empty; collapse `\r\n`/`\r` → `\n`; `Trim()`.
  - `ResolveHivePath`: `Path.Combine(mountPath, "Windows", "System32", "config", <file>)` where `<file>` is `SOFTWARE` for `HKLM\SOFTWARE`, `SYSTEM` for `HKLM\SYSTEM`, else `hive.Replace('\\','_')`.
  - `CompareRegistry`: per-hive `FullPath`→value dictionaries (first-wins on duplicates, ordinal-ignore-case); `Added` = only in difference; `Changed` = both but data or type differ; `Removed` = only in reference; sort each list by `FullPath`; set counts + `HasRegistryData`.
