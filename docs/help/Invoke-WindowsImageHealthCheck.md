# Invoke-WindowsImageHealthCheck

## SYNOPSIS
Runs a composite health check against one or more mounted Windows images.
## SYNTAX

```
Invoke-WindowsImageHealthCheck [-MountedImages] <MountedWindowsImage[]> [-RestoreHealth] [-ContinueOnError]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Runs configurable health checks against mounted images (for example corruption and servicing state) and computes an OverallHealth result with per-check findings. SupportsShouldProcess is honored.
