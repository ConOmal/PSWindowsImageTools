# Get-WindowsImageComponentStore

## SYNOPSIS
Analyzes the WinSxS component store of one or more mounted Windows images.
## SYNTAX

```
Get-WindowsImageComponentStore [-MountedImages] <MountedWindowsImage[]> [-ContinueOnError]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION
Reports component store package counts, size, and cleanup candidates (superseded and cached components) per mounted image. Pairs with Optimize-WindowsImageComponentStore for actual cleanup.
