# Get-WindowsImageFeatureList

## SYNOPSIS
Lists Windows features in mounted images.
## SYNTAX

```
Get-WindowsImageFeatureList [-MountedImages] <MountedWindowsImage[]> [-Filter <String>]
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION
Enumerates DISM features per mounted image. Filter narrows by regex on feature name.
